# src/ — frontend / Svelte + TS gotchas

Loads when working under `src/`. Root invariants live in [../AGENTS.md](../AGENTS.md). Easy to get wrong without reading the spec — internalize before touching tree / rename / sidecar / mutation / viewer code.

## Mutation safety (non-negotiable)

- **Every file-modifying action routes through [lib/mutate/backup.ts](lib/mutate/backup.ts)** — `beginOperation(root, statePaths, meta, fs?)` → `ctx.writeText`/`writeBytes`/`rename`/`delete`/`commit`/`rollback`; single-step callers use `atomicWriteText`/`atomicWriteFile`/`renamePath`. JSONL op-log with typed `children`; LIFO rollback on mid-op failure. `OpType` is the single `OP_TYPES` const in backup.ts; `KNOWN_OP_TYPES` in operationsLog.ts DERIVES from it (`new Set(OP_TYPES)`) — never hand-maintain a parallel allowlist.
- **`ctx.writeNewText` is the refuse-on-exists twin of `ctx.copyInto`** — use it (never `writeText`, which overwrites) for any "write a NEW dataset file" path. Both finalize via `ctx.finalizeNewFileNoReplace` (Rust OS no-replace move + exclusive-create fallback), NEVER plain `rename` (overwrites on POSIX). A target appearing mid-op is preserved + no `write` child recorded.
- **Every action-layer mutator acquires a `MutationLease`** ([lib/mutate/lease.ts](lib/mutate/lease.ts)) before any work, releases in `finally`. `scope`: file(P) / dataset(R) / global. Conflict matrix: global ⊥ everything; file⊥file iff equal; dataset⊥dataset iff containment; file(P)⊥dataset(R) iff P under R. Single sidecar → file; batch/rename/undo/import → dataset; deface/revert → file + `snapshotFreshness`; Reset → global. Preview is advisory; **apply recomputes the plan fresh under the lease** (merge/events/minimize all do this; a materially-changed reviewable surface throws `*StaleError`).
- **All per-dataset state lives under app-data, NOT in the dataset.** `<appDataDir>/datasets/<safeKey>/` (`safeKey = base64url(SHA-256(absPath)).slice(0,32)`) holds prefs/operations.log/pending/originals. The one exception: `<dataset>/sourcedata/` is the M7-deface pristine-bytes mirror. This is why BIDSvue is safe on read-only / cloud-mounted / conformance-strict datasets.
- **Long-running mutation wrappers capture `scanGeneration` + `datasetStore.dataset?.root` at ENTRY**, only rescan/auto-open if both still match in `finally` (`withOpenDatasetAndRescan`; import bypasses but guards inline). Recurs every time a mutation grows a `finally { … }` post-action block.

## Tree / rename / selection

- **Pairing display:** sibling files sharing a true *leading* BIDS-entity prefix (walk `CANONICAL_ENTITY_ORDER`; stop at first divergence; never a set intersection) coalesce into one row. Sidecars coalesce with their data file; multi-echo/multi-part stay separate. `showFullFilenames` toggle = one row per member. Algorithm: [lib/bids/pairing.ts](lib/bids/pairing.ts).
- **Entity-typed renames** ([lib/rename/](lib/rename/)): `sub-`/`ses-`/`acq-` are typed values, never substring search. Folder entities (sub/ses) rename folders + descendants + cross-refs (`IntendedFor`, `*_scans.tsv`, participants.tsv); filename entities are dataset-wide basename renames. Word-boundary regex protects `run-1`→`run-2` from `run-10`. `derivatives`/`sourcedata`/`code` out of scope.
- **Entity removal / minimize** ([lib/rename/removePlan.ts](lib/rename/removePlan.ts), shared by Edit>Minimize + AI `remove_entity`): only `REMOVABLE_ENTITIES`; `sub`/`task`/`sample` REFUSED; removing `ses` requires exactly ONE session/subject; NEVER recursive-delete a session dir (use `removeEmptyDir`); stripped-name collision caught at plan time.
- **Selection has three decoupled axes:** `selectedPaths` (rows), `primaryPath` (Preview pane), `activeIdentity` (keyboard cursor). Plain click/arrow replaces all three; Shift-arrow extends selection + moves only the cursor; Preview group-tabs use `setPreviewTarget(path)` — the ONLY legitimate way primaryPath diverges from selectedPaths. Tempted to call `setSelection` from a non-tree surface → you want `setPreviewTarget`.
- **Hidden/visible/dimmed:** `isHiddenByDefault(name, isTopLevel)` ([lib/bids/level.ts](lib/bids/level.ts)) is the single source. Off: skip dotfiles + root `sourcedata/`. On: show but dim special folders (`sourcedata`/`derivatives`/`code`/`.heudiconv`/`.bidsvue`/…) + dotfiles. `.bidsignore` honored both ways; special folders always excluded from validator scope.

## Editors + identity protection

`Preview.svelte` routes `.json → SidecarEditor`, `.tsv → TsvEditor`, else-text → `TextEditor`. Text allowlist in [lib/util/fileFormat.ts](lib/util/fileFormat.ts) — **don't widen casually; every extension gains a write surface.** Editable dotfiles need BOTH the TS allowlist AND the `apply_widen_dataset` Rust carve-out. All three editors share `saveSidecar`'s lease + atomic-write + read-only backstop. `participants.tsv` identity protected at TsvEditor (`participant_id` cells locked; row-delete refused while a matching `sub-XXX/` folder exists). **SidecarEditor raw-buffer authority:** the View textarea is authoritative ONLY in view mode AND `rawDirty`; `setMode` MUST drop `rawDirty`+`rawError` on any non-view transition (stale raw buffer replaying over structural edits = data loss); `rawError` blocks save in every mode. **Physio `*_recording-*_physio.tsv.gz` is read-only** (not in the text allowlist) — high-freq gzipped timeseries; the `.json` sidecar IS editable.

## DataLad symlinks (frontend)

plugin-fs canonicalizes relative annex symlinks incorrectly. **Read side:** any `stat`/`exists`/`readFile`/`readTextFile`/`copyFile`-source on a dataset path MUST pre-resolve via `resolveSymlinkIfPresent`; any `rename` whose dest could be a symlink MUST use `renameWithRustFallback` (both in [lib/util/readTextFile.ts](lib/util/readTextFile.ts)) — else fetched pointers throw `forbidden path … allow-stat`/`allow-rename`. **Write side is deliberately asymmetric:** `tauriMutateFs.{writeFile,rename,remove}` do NOT pre-resolve — atomic-write's temp+rename MUST replace the symlink with a fresh regular file (pre-resolving would overwrite the shared content-addressed annex blob and corrupt every dataset sharing that key). Decide a new mutate-fs method's lane up front. Un-fetched pointers: filtered from validation, refused by deface/revert with `PointerNotFetchedError`, shown with a cloud chip.

## Svelte 5 reactivity traps

- **`datasetStore.dataset` is a DEEP `$state` proxy; a raw in-place mutation of a `byPath` FileNode is INVISIBLE to tree reads even with a `revision` bump.** `byPath` is a plain Map whose values Svelte doesn't proxy. RAW byPath consumers (StatusBar tally) see the mutation; the proxied tree row does NOT. So "flip `contentPresent` in place + bump revision" is reliable only for raw byPath consumers; the tree chip needs a `dataset` REASSIGNMENT (→ fresh proxy) to clear. `fetchPointers` schedules a debounced `rescanCurrentDataset()` for exactly this. Any "mutate dataset deeply + bump revision" that a PROXIED consumer must reflect MUST rescan instead (or migrate `dataset` to `$state.raw`).
- **Per-dataset DataLad capability cache** ([lib/state/datasetCapability.svelte.ts](lib/state/datasetCapability.svelte.ts)) MUST use `SvelteMap`, not plain `Map` (a plain Map is invisible to `$derived`). `loadCapability` captures a per-root epoch + short-circuits on advance.
- **`$effect` consumers of long-lived flags MUST `untrack()` the flag the effect mutates** (e.g. `transcriptStore.busy`), AND diff dataset-change effects against a captured previous root (`datasetStore.dataset` mutates on scan progress → new ref even when `.root` unchanged). Both gates load-bearing. **Set-busy/clear-busy MUST sandwich set-handle/clear-handle** so "busy=true implies handle≠null" never breaks.
- **Viewer attach race-closure** ([lib/viewer/attachPhysio.ts](lib/viewer/attachPhysio.ts) / attachSpectroscopy.ts is the reference): `removeAll<X>()` INSIDE the serialised chain after `await prev.catch(()=>{})`; load-token recheck BEFORE attach AND after the `loadSignals` resolve. Any `loadSignals`/`loadMeshes` follow-up-attach MUST follow it. SVS `$effect`s driving async work re-check `(destroyed, path===target, showHeader, loadToken)` in BOTH resolve and reject arms.

## Dataset file watcher (auto-revalidate)

- **The watcher gates on event KIND, not just path** ([lib/state/datasetWatcher.ts](lib/state/datasetWatcher.ts) `isContentRelevantKind`). Each fire runs a full `rescanCurrentDataset()` → `openDataset()`, which re-reads every dataset file. On Linux `notify`/inotify reports the scan's OWN reads (`access` open/close-read) and atime bumps (`modify`/`metadata`), so revalidating on those creates a tight scan→atime→rescan loop that pins CPU + flickers the whole UI. macOS FSEvents reports neither, so it only ever bit Linux (fixed 2026-06-30). **Do NOT relax this filter to revalidate on `access` (except `close`-`write`) or `metadata` events.** Two non-obvious constraints: (1) `close`-after-**write** (`IN_CLOSE_WRITE`) IS kept — it's an edit-completion signal distinct from close-read, and the scan never emits it; (2) **all** `metadata` is dropped, NOT narrowed by `mode` — Linux `IN_ATTRIB` has no sub-type so `notify` collapses atime and `chmod` into `Metadata(Any)`; keeping permissions would re-open the loop. Cost: an external `chmod` won't refresh read-only lock chips until the next content event (UI-staleness only — the save path is independently mode-guarded). 800 ms debounce + path filter (`shouldRevalidate`) still apply on top.

## Viewer routing + i18n + misc

- **Spectroscopy routing is dim-based, not suffix-based:** `probeNiftiKind(path, fs)` ([lib/deface/headerProbe.ts](lib/deface/headerProbe.ts)) is the SOLE source for volume / svs (dim1=dim2=dim3=1 AND dim4>1) / file-only routing. Do NOT branch on BIDS suffix. Fails open to `'volume'` on ENOENT/parse-failure/NIfTI-2.
- **4D deface guard** lives inside `runDeface`/`runMindgrab` via `ensureNotFourD` (reads only the 352-byte header; gzip-streamed for `.nii.gz`); throws `FourDRejectedError` if `dim[0]>3` or `dim[4]>1`. NIfTI-2 also rejected. Batch surfaces per-file without aborting.
- **i18n discipline:** UI strings through `$_(…)`; **BIDS data values do NOT** (sidecar fields, entity labels, validator codes stay canonical English, `.`-decimal). Native menus (`appMenu.ts`/`contextMenu.ts`) are English-only by policy (don't route through `$_` — `check-i18n` can't catch new menu strings). Locale from `preferencesStore.locale` (`null`=auto). pt/es are AI-bootstrapped (`humanReviewed:false`).
- **Importer-authored text files are LF** (`*_scans.tsv`, participants.tsv, README, scaffolding JSON…). Use `toLfEol` ([lib/util/eol.ts](lib/util/eol.ts)) at the construction boundary. Files routed through `saveSidecar`/editors preserve the user's EOL — the LF rule is only for files BIDSvue authors fresh.
- **`moveStemFiles`** ([lib/import/postpass/moveStem.ts](lib/import/postpass/moveStem.ts)) is the SOLE primitive for grouped (companion-extension) renames — never reintroduce a private mover. Counters MUST gate on `moved > 0` (a concurrent move can empty the source between probe and rename). `BIDS_DATATYPES` gates BOTH the move phase AND the filename-fallback discovery in `sessionBackfill.ts` (a `_ses-X` name inside `code/`/`stimuli/`/`sourcedata/` must not influence session choice). Physio rescue REQUIRES both `.tsv.gz` AND `.json` companions (a half-pair is BIDS-invalid + risks Pass-4 derivatives deletion).
- **AI chat lifecycle is dataset-scoped, not window-scoped** ([lib/ai/chat.svelte.ts](lib/ai/chat.svelte.ts)): survives AIWindow close+reopen; `bindToDataset(root)` drops the conversation on dataset close/switch; "Clear conversation" rotates the session id. Window close NEVER drops state. Compose textarea: plain Enter sends, Shift+Enter newline, `e.isComposing` guard is load-bearing (IME). Permission toggles share one `permissionsPending` hint, cleared at next Send.
- **Synthetic `*_bold` NIfTI fixtures MUST declare 4D dims** (`BOLD_DIM_4D = [4,64,64,30,60,1,1,1]`) — Pass 0c demotes a 3D BOLD stem to `*_sbref` and breaks downstream test expectations.
